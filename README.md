# DesktopVeil · 桌面一键隐藏

DesktopVeil 是一款 Windows 桌面工具，可以一键隐藏桌面图标和任务栏，并恢复隐藏前的显示状态。圆形按钮停靠在屏幕侧边，鼠标离开约 1 秒后收起，移入侧边提示条时展开。

![展开的圆形按钮和收起后的侧边提示条](按钮预览.png)

## 使用

当前版本为 **1.2.0**。解压免安装包后，双击 `DesktopVeil.exe` 立即隐藏桌面图标和任务栏。

- 左键点击 **显** 恢复显示，点击 **隐** 再次隐藏。
- 拖动按钮后松开，可以调整高度并吸附到左侧或右侧。
- 右键选择 **恢复并退出**，退出前会还原显示状态。
- `Ctrl + Alt + F10` 切换显示状态，`Ctrl + Alt + F11` 恢复显示。

如果进程被强制结束，再次启动会尝试恢复上一次的显示状态。详细操作和异常恢复见[使用说明](使用说明.md)。

## 兼容性

已在 **Windows 10 22H2 和 .NET Framework 4.8** 的单屏环境验证。Windows 11、真实多屏和混合 DPI 尚未完成实机验证。程序使用当前用户权限运行，数据保存在 `%LOCALAPPDATA%\DesktopVeil`，无需联网。

## 从源码构建

在项目根目录打开 PowerShell，使用系统自带的 .NET Framework C# 编译器。项目无需安装第三方依赖。

```powershell
& '.\source\build.ps1'
& '.\source\tests\run-tests.ps1'
```

生成的 `DesktopVeil.exe` 位于项目根目录。常规测试在临时目录编译。需要验证实际桌面时，先退出正在运行的 DesktopVeil，再传入 `-Live`。实机测试会短暂隐藏和恢复当前桌面。

更多细节见[验收记录](验收记录.md)和[项目安全审计](项目安全审计.md)。
